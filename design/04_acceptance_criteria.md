# 受け入れ基準：Magnetite（統合再設計版）

| 項目 | 内容 |
|---|---|
| ドキュメントバージョン | 0.1（ドラフト） |

各基準は Given / When / Then で記述し、US・F・（後続で）S と紐付ける。エラーメッセージ文言は本書で確定する。

## 横断共通機能

### AC-01：SSO ログイン（US-01 / F-01）
- **Given** SSO 接続が設定され、利用者が未認証である
- **When** ログイン画面で「SSO でログイン」を選び、SSO 側で認証に成功する
- **Then** セッションが確立し、ロールが確定した状態で統合ダッシュボードへ遷移する
- **異常**：state 不一致またはトークン交換失敗時、`SSO ログインに失敗しました。もう一度お試しください。` を表示しログイン画面に留まる

### AC-02：ローカルログイン（US-02 / F-01）
- **Given** 有効なローカルアカウントが存在する
- **When** 正しいユーザ名とパスワードを入力する
- **Then** セッションが確立しダッシュボードへ遷移する
- **異常**：資格情報が不正な場合、`ユーザ名またはパスワードが正しくありません。` を表示する（どちらが誤りかは示さない）

### AC-03：初回セットアップ（US-03 / F-01）
- **Given** ローカルアカウントが 1 件も存在しない初回起動状態である
- **When** 初期セットアップ画面で管理者ユーザ名とパスワード（ポリシー適合）を登録する
- **Then** Admin ロールの初期アカウントが作成され、ログイン画面へ遷移する
- **異常**：パスワードがポリシー未達の場合、`パスワードは8文字以上で、英字と数字を含めてください。` を表示する

### AC-04：ロール認可（US-04 / F-02）
- **Given** 認証済みセッションのロールが Viewer である
- **When** 更新系（作成/更新/削除）または制御系操作を試みる
- **Then** 当該操作ボタンは非活性で、直接要求時は `この操作を行う権限がありません。` を表示し実行しない
- **補足**：更新系は Operator 以上、破壊的/制御/設定/アカウント管理は Admin を必須とする

### AC-05：アカウント/セッション管理（US-05 / F-10）
- **Given** Admin としてログインしている
- **When** ローカルアカウントを作成/削除、またはアクティブセッションを失効させる
- **Then** 変更が即時反映され、失効セッションは次回リクエストで無効化され、操作が横断監査ログに記録される
- **When** ローカルアカウントのパスワードをリセットする
- **Then** 新パスワードがポリシー検証（8文字以上・英数字含む）を通れば更新され監査記録される。未達は `パスワードは8文字以上で、英字と数字を含めてください。` を表示
- **When** ローカルアカウントを削除/無効化する
- **Then** そのアカウントの全アクティブセッションが即時に失効する（09 §6.5）
- **異常**：最後の Admin アカウント削除/降格を試みると `最後の管理者アカウントは削除できません。` を表示し拒否する

### AC-05b：ログアウト（US-01,US-02 / F-01）
- **Given** 認証済みである
- **When** ヘッダーのユーザーメニューからログアウトする
- **Then** 現在のセッションが失効し（SSO 時はトークンも破棄）、`S-Login` へ遷移する。操作は監査記録される

### AC-06：統合ダッシュボード（US-06 / F-03）
- **Given** 認証済みである
- **When** ダッシュボードを開く
- **Then** 8 ドメインの稼働状況（正常/警告/異常/不明）と主要指標が一覧表示され、一定間隔で自動更新される
- **状態**：データ取得中はスケルトン表示、取得失敗ドメインは `状態を取得できませんでした` バッジを表示する

### AC-07：横断監査ログ（US-07 / F-04）
- **Given** 監査ログが蓄積されている
- **When** 日時・実行者・ドメイン・操作種別でフィルタし一覧を開く
- **Then** 日時/実行者/ドメイン/操作/対象/IP/結果 が時系列で表示され、ページングで遡れる
- **状態**：該当 0 件時は `条件に一致する監査ログはありません。` を表示する

### AC-08：アラート確認・対応（US-08 / F-05）
- **Given** open 状態のアラートが存在する
- **When** アラートを確認応答（acknowledge）または解決（resolve）する
- **Then** 状態が open→acknowledged→resolved に遷移し、実行者と日時が記録され監査ログに残る
- **異常**：既に resolved のアラートを再解決しようとすると操作は非活性

### AC-08b：通知先（NotificationTarget）管理（US-08 / F-05）
- **Given** Operator 以上でログインしている
- **When** 通知先（Webhook 等）を作成/更新/削除する（S-Alerts 通知設定タブ）
- **Then** 名称（一意）・endpoint（URL）・最小重大度・対象ドメイン・有効/無効が保存され、以後のアラートは送信条件（08_alerting §4）に従って通知される。操作は監査記録される
- **異常**：URL 不正は `有効な URL を入力してください。`、名称重複は `同じ名称が既に存在します。` を表示し保存しない

### AC-09：バックアップ/リストア（US-09 / F-06）
- **Given** Admin としてログインし、対応ドメインが選択されている
- **When** バックアップを作成、または既存バックアップからリストアする
- **Then** バックアップにメタデータ（作成日時/サイズ/対象）が付与され一覧に現れ、リストアは確認ダイアログ承認後に実行され監査記録される
- **異常**：リストア対象が破損/非互換の場合 `このバックアップはリストアできません（形式が不正です）。` を表示する

### AC-10：テンプレート適用（US-10 / F-07）
- **Given** 対応ドメインに登録済みテンプレートが存在する
- **When** テンプレートを選択して対象へ一括適用する
- **Then** 適用結果（成功/スキップ/失敗の件数）が表示され、変更が監査ログに記録される
- **異常**：既存設定と競合する場合、適用前に競合一覧と `N 件が既存設定と競合します。` を提示する

### AC-11：統合ログ閲覧（US-11 / F-08）
- **Given** ドメインが動作ログ/クエリログ/アクセスログを出力している
- **When** ドメインとログ種別を選んでビューアを開く
- **Then** タイムスタンプ・レベル・メッセージが逆時系列で表示され、レベルフィルタと追尾（自動更新）ができる
- **状態**：ログが空のとき `表示できるログがありません。` を表示する

### AC-12：言語・テーマ・設定（US-12 / F-09）
- **Given** 認証済みである
- **When** 言語(ja/en)またはテーマ(dark/light)を切り替える
- **Then** 表示が即時に切り替わり、選択が次回ログインでも保持される
- **補足**：システム設定（接続/ポリシー等）変更は Admin のみ可能で、保存時に設定リロードが行われる

## ドメイン管理機能（共通 CRUD ＋ 固有操作）

> 各ドメインは下記の共通 CRUD 基準（AC-CRUD）を満たしたうえで、固有操作の基準を追加する。

### AC-CRUD：ドメイン共通の CRUD（全ドメイン / F-11〜F-18）
- **一覧**：Given データが存在する When 一覧を開く Then 検索・フィルタ・ページング付きで表示。0 件時 `データがありません。`
- **作成**：When 必須項目を満たして保存 Then 追加され成功トースト表示。検証違反時は当該項目の下に確定文言（各ドメイン画面仕様で定義）を表示し保存しない
- **更新**：When 変更保存 Then 反映され成功トースト
- **削除**：When 削除操作 Then 確認ダイアログ提示 → 承認で削除・監査記録。参照されている対象の削除は参照整合（07 参照マップ）に従う
- **権限**：参照=Viewer、作成/更新/削除=Operator、破壊的な一括操作=Admin

### AC-13：DNS 固有（US-13 / F-11）
- ゾーン削除時、配下レコードがある場合 `このゾーンには N 件のレコードがあります。まとめて削除しますか？` を確認する
- クエリテスト実行時、解決結果（応答コード/回答レコード/所要時間）を表示する
- RPZ ルールの適用/解除が即時反映され監査記録される

### AC-14：DHCP 固有（US-14 / F-12）
- リース解放時、確認後に該当リースが解放され一覧から消える。既に期限切れのリース解放は非活性
- プールと予約（固定割当）のアドレス範囲重複時 `指定範囲は既存プールと重複しています。` を表示し保存しない

### AC-15：LDAP 固有（US-15 / F-13）
- LDIF インポートで各エントリの成功/失敗を件数と行番号付きで表示、失敗行はスキップし処理継続
- ユーザの有効/無効切替が即時反映される。パスワードリセットは Admin のみ
- 親 OU 削除時、配下エントリがある場合 `この OU には配下エントリがあります。先に移動または削除してください。` を表示し拒否する
- ACL ルールの作成/更新/削除時、対象 DN・主体・操作・効果（allow/deny）を検証して保存し監査記録する（評価順序は 08_ldap_logic §2.2）。必須欠落は該当項目に確定文言を表示し保存しない

### AC-16：Mail 固有（US-16 / F-14）
- ドメイン削除時、そのドメインに属するメールユーザ/エイリアスがある場合は拒否し `このドメインには N 件のアカウントがあります。` を表示
- エイリアス作成時、宛先が存在しないメールユーザを指す場合 `宛先のアカウントが存在しません。` を表示

### AC-17：Proxy 固有（US-17 / F-15）
- 証明書の有効期限が近い/超過した仮想ホストを一覧でバッジ表示（`まもなく期限切れ`/`期限切れ`）
- ACL ルール/IP ブロックの優先度変更が即時反映され、アクセスログにヒットしたルールを表示できる

### AC-18：コンテナ/K8s 固有（US-18 / F-16）
- アラートルールの有効/無効切替が即時反映される
- クラスタ/ホストのアラート確認応答が状態遷移し監査記録される（AC-08 に準拠）

### AC-19：SSO 固有（US-19 / F-17）
- プロバイダ/クライアント設定変更が保存時に検証され、必須項目欠落時は該当項目に確定文言を表示
- セッション失効操作で対象セッションが無効化される（AC-05 に準拠）

### AC-20：監視(Watch) 固有（US-20 / F-18）
- 監視ルールの閾値・重大度を設定でき、条件成立でアラートが open として生成される
- メンテナンス窓の期間中は該当ホストのアラートを抑止し、`メンテナンス中` バッジを表示する
- アラートの確認/解決は AC-08 に準拠する
