# 標準UIキット：Magnetite（統合再設計版）

| 項目 | 内容 |
|---|---|
| ドキュメントバージョン | 0.1（ドラフト） |
| 最終更新日 | 2026-07-05 |
| ステータス | ドラフト |

全画面が再利用する**標準UI部品**を定義する。UI/UX統一（本移行の目的）の実体であり、各 `screen_*.md` はこれらを組み合わせて記述する。方針は「**標準提供＋テーマ調整**」——レイアウト/挙動は本キットが固定提供し、見た目は 06 トークン、文言は i18n(ja/en) で調整する。

## 0. 方針（確定）

- **共通部品を単一の正**とし、全ドメイン画面で同一の見た目・操作・状態表現を保証する（S-00 を継承）。
- 見た目＝ 06_design_tokens、文言＝ i18n キー、状態色＝状態/重大度セマンティクス（06 §2）。
- ドメイン固有UI（LDAPツリー等）も、共通部品（テーブル/フォーム/ダイアログ）の上に構築する。

## 1. 共通シェル

### 1.1 AuthenticatedShell（サイドバー＋ヘッダー＋コンテンツ）
```
[≡] Magnetite    [🔔N][🌐][🌓][👤 user▾]   ← ヘッダー(header-height 56px)
────────────┬──────────────────────────
サイドバー   │  <ページ>

```
| 部品 | 仕様 | トークン/データ |
|---|---|---|
| Sidebar | 3グループ（横断/8ドメイン/管理）。現在地ハイライト。ロールで出し分け（Viewerは管理非表示）。折りたたみ 56px | `layout.sidebar-width` / `DomainConfig.icon` / `domains.enabled` |

- 認証ガード：未認証は全ページ `S-Login` へ（09 §1）。

## 2. 標準部品カタログ

### 2.1 PageHeader
- 構成：タイトル（`font.h1`）＋（任意）説明＋右側に主要アクション（PrimaryButton）＋検索。
- 用途：全一覧/詳細画面の最上部（S-00, 各ドメイン）。

### 2.2 DataTable
| 項目 | 仕様 |
|---|---|
| 行高 | 40px、ホバー背景 `color.bg-subtle`、ゼブラなし |
| 列 | ソート可（見出しに矢印）、行選択（一括操作時）、末尾に行アクション |
| 状態 | 空/読込中/正常/エラー を内包（§4） |
| ページング | 2ページ以上で Pagination 表示 |
| レスポンシブ | 狭幅は主要列＋行展開（S-00 §7） |

### 2.3 FilterBar
- 検索ボックス（`/`でフォーカス、デバウンス）＋ドロップダウンフィルタ群＋件数表示。変更で再取得しページを1に戻す。

### 2.4 FormCard / SlideOver
- 作成/編集は右スライドオーバー（`layout.slideover-width` 480px、`elevation.3`）。一覧の文脈を保持。
- ラベルと入力を関連付け、検証エラーは項目直下に赤字（`color.danger`）。保存中はボタンをスピナー化し二重送信防止。
- ショートカット：`n`新規、`Esc`閉じる（変更ありは破棄確認）。

### 2.5 ConfirmDialog
- 破壊的操作（削除/リストア/制御）で必須。フォーカスを移し `Esc`/取消で閉じる。
- 文言は呼び出し側が確定（各AC/画面のイベント表。例 `<対象>を削除します。よろしいですか？`）。

### 2.6 Toast
- 操作結果通知。成功=`color.success`／失敗=`color.danger` の左ボーダー＋アイコン、既定4秒で自動消去、複数はスタック。

### 2.7 StatusBadge / SeverityBadge
- **色＋テキスト**（色覚非依存）。状態/重大度セマンティクス（06 §2）に一対一。
- 稼働：正常/警告/異常/不明。アラート：未対応/確認済/解決済/メンテナンス中。

### 2.8 Pagination
- 前/次＋現在ページ/総ページ。1ページ既定 50〜100件（05 §1）。

### 2.9 補助
| 部品 | 仕様 |
|---|---|
| PrimaryButton/SecondaryButton | `color.primary`/枠線。押下フィードバック必須 |
| Skeleton | 読込中のテーブル行/カードのプレースホルダ |
| EmptyState | 空メッセージ（画面ごとに確定文言）＋（権限あれば）追加導線 |
| ErrorState | エラー文言＋[再試行] |
| Tabs | S-Alerts/一部ドメインのタブ切替 |
| LogViewer | 仮想リスト・レベル色・追尾トグル（S-Logs）。等幅 `font.mono` |
| MetricChart | 時系列表示（S-Dash/Watch）。色は状態セマンティクス |

## 3. 標準フォーム部品（入力）

| 部品 | 仕様 | 検証表示 |
|---|---|---|
| TextInput / NumberInput | ラベル＋入力＋補助文。数値は範囲 | 直下に確定文言 |
| Select / MultiSelect | enum選択（06） | `いずれかを選択してください。` |
| Toggle | 有効/無効・ON/OFF（即時反映系） | — |
| PasswordInput | マスク。ポリシー表示 | AC-03 文言 |
| KeyValue / JSON/YAML エディタ | 設定・テンプレ body（等幅） | 構文エラー表示 |

## 4. 標準状態表現（全画面共通・必ず網羅）

| 状態 | 標準表示 | 部品 |
|---|---|---|
| 空(Empty) | 確定文言＋導線 | EmptyState |
| 読込中(Loading) | スケルトン | Skeleton |
| 正常(Success) | データ表示 | DataTable 等 |
| エラー(Error) | 文言＋再試行 | ErrorState |
| 検証エラー(Validation) | 項目直下に赤字 | Form部品 |
| 権限不足(Forbidden) | ボタン非活性＋`この操作を行う権限がありません。` | Button/AC-04 |
| 処理中(Submitting/Progress) | スピナー・二重防止 | Button/進捗 |

> この7状態の網羅は S-00 §3 と一致。各画面は差分のみ記す。

## 5. テーマ・用語・項目の適用

| 調整 | 出所 |
|---|---|
| 色/フォント/角丸/影/レイアウト | 06_design_tokens（ライト/ダーク、状態色） |
| ドメイン表示名・アイコン・表示ON/OFF | 07 §3.10 `DomainConfig`（display_name/icon/enabled） |
| 文言（多言語 ja/en） | i18n キー（日本語を正、en訳を対に） |
| ロール別の表示/非活性 | 08_authz（決定表） |

## 6. アクセシビリティ（キット共通）

- キーボードのみで主要操作が完結（`/`検索・`n`新規・`Esc`閉、テーブル行移動、Enter送信）。
- フォーカスリング常時可視（`color.focus` 2px）。ダイアログ表示でフォーカス移動、`Esc`で閉じる。
- 状態は色＋テキスト/アイコン。コントラスト WCAG AA（05 §3）。
- アイコンボタンに aria-label、テーブルは適切なセマンティクス。
